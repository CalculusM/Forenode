# Forenode 전향 등록소 — 예측 사전등록·공개 채점

> **목적**: 결과가 나오기 전의 예측을 날짜 도장과 함께 봉인해, "결과를 알고 끼워 맞췄다"는 의심을 원천 차단한다.
> 의학 임상시험 사전등록(pre-registration)의 민자도로 재무검증 버전. Forenode 정확도 검증의 **모든 기록은 이 섹션에 축적**되며, 여기서 피칭·보고서가 산출된다.

## 등록소 구성
- `README.md` — 규약 (이 문서, 개정 시 이력 기록)
- `REG-YYYY-NNN-*.md` — 개별 등록서 (**등록 후 불변** — 수정은 새 버전 파일로만)
- `verification-log.md` — 채점·사후검증 로그 (백테스트 포함 전체 정확도 기록의 단일 원장)

## 등록 규약 (v1, 2026-07-14 제정)
1. **봉인**: 등록서는 위키 깃 저장소에 커밋한다. **커밋 해시가 날짜·내용의 위변조 불가 증거**다. (공개 검증력 강화를 위해 원격 push 병행)
2. **불변**: 등록서는 커밋 후 수정하지 않는다. 모델이 개선되면 새 등록서(v2, v3…)를 추가한다 — 구 버전과 신 버전의 채점 비교가 곧 "개선의 증명"이 된다.
3. **범위 예측**: 점추정이 아닌 P10/P50/P90 밴드로 등록한다 (Forenode 원칙과 동일).
4. **as-of 명시**: 등록 시점에 사용한 데이터·모델 버전(코드 커밋 해시)을 기재한다.
5. **채점 트리거**: 국토교통부 「민자도로의 건설 및 유지·관리 현황 보고서」 연도판 발간(매년 5/31 국회 제출) 시 해당 연도 실측/협약 비율로 채점하고 `verification-log.md`에 기록한다.
6. **채점 지표**: ① 밴드(P10~P90) 적중 여부 ② |실측 − P50| 오차(%p) ③ 여러 건 누적 시 밴드 적중률(목표: 80% 내외 — P10~P90 설계상 기대치).
7. **탈락 없는 보고**: 빗나간 예측도 삭제·은폐하지 않고 그대로 채점·공개한다. 빗나감의 원인 분석이 모델 개선 입력이 된다.

## 예측 대상의 정의
- **전향(prospective)**: 등록 시점에 실측이 공표되지 않은 연도의 실현율(실측 교통량 ÷ 협약 교통량). ※ 2025년 실적은 2025년도 보고서(2026년 발간)로 공표되었거나 임박했으므로 **2026년 실현율부터** 전향으로 인정.
- **조건부 등록**: 협상 단계 노선은 실시협약 체결(협약 교통량 확정) 확인 후 30일 내 본등록한다. 그 전에는 등록 예약으로 기재.

## 사후검증(백테스트)과의 관계
사후검증은 [[verification-log]]에 기록한다. 전향 등록과 사후검증은 같은 원장의 두 면이다:
- 사후검증 = "과거를 얼마나 맞추는가" (표본 확대·모델 개선의 근거)
- 전향 등록 = "미래를 미리 맞춘다고 공언" (신뢰의 증거)
피칭·보고서는 이 두 기록에서만 수치를 인용한다 (단일 출처 원칙).
