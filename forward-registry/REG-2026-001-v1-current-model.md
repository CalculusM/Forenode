# REG-2026-001 — 현행 배포 모델(v1) 전향 예측

> **등록일**: 2026-07-14 · **등록자**: 지범구 (Forenode)
> **봉인**: 본 파일의 위키 저장소 최초 커밋 해시가 봉인 증거 (커밋 후 본문 불변)
> **모델**: 현재 라이브 배포 중인 Forenode 수요 낙관편향 모듈 그대로 (demand_bias.py, 코드 저장소 main 및 feat/c1-opex-cashflow-wiring@8180179 기준)

## 예측 규칙 (v1 — 등록 시점의 배포 모델)
- **개통 1~3년차**: prior "도로 — 국내 민자 보수(초기군)" lognormal(중앙값 0.55, σ 0.30)
  → 실현율 **P10 37% / P50 55% / P90 81%**
- **개통 4년차 이후**: prior "도로 — 국내 실측 22개 노선(KOTI '22~'24)" Normal(0.814, 0.2025)
  → 실현율 **P10 55% / P50 81% / P90 107%**
- 실현율 = 해당 연도 실측 일평균 교통량 ÷ 실시협약 예측 교통량 (국토부 연도별 현황보고서 기준)

## as-of 데이터 명시 (등록 시점에 알고 있던 것)
- 포천-화도 2024년 실현율 55.3%, 평택-부여 2024년 45.9% (국토부 2024년도 보고서, KOTI RR-25-10 p.141 재인용) — **이 값들은 등록 전 공개 정보이므로 채점 대상이 아님**
- 2025년 실현율은 2025년도 보고서(2026년 발간 주기)로 공표 — 등록일 현재 미확인이나 공표 임박 가능성이 있어 보수적으로 **채점 대상에서 제외**, 2026년분부터 채점
- 22개 노선 '22~'24 실현율 분포 (동 보고서 p.12)

## 정직 고지 (한계)
1. v1 초기군 prior(0.55)의 근거에는 과거 노선(천안논산·인천공항·우면산)의 초기 실적이 포함됨 — 등록 대상 노선들과는 독립이나, 소표본 기반의 보수적 prior임
2. v1은 연차 구분 2단(1~3 / 4+)의 단순 규칙 — 2026-08 예정인 패널 학습 모델 v2(램프업 곡선·공변량)가 REG-2026-002로 재예측하면, **v1 vs v2의 채점 비교가 모델 개선의 객관 증거**가 됨
3. 광명-서울·협상 4건의 개통 시기는 미정 — 연차 기준으로 등록해 개통 지연과 무관하게 채점 가능
